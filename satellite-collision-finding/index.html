Architecture

For each bucket window [T, T+bucket]:
  1. CPU: SGP4 propagate all sats at T and T+bucket (reuse previous T+bucket as new T)
  2. GPU: SLERP interpolate positions at 1-second intervals 鈫?cell entries
  3. GPU: Radix sort entries by (time_offset << 26) | cell_id
  4. GPU: Collision detection on sorted entries 鈫?candidate pairs
  5. CPU: Refine TCA for unique pairs using linear algebra root find/rejection

About Space Debris Tracking

There are over 30,000 tracked objects in Earth orbit, and the risk of collision grows as more satellites launch each year. This tool screens the entire satellite catalogue for close approaches 鈥?conjunctions where two objects pass within a few kilometres of each other. Results are computed every 4 hours using GPU-accelerated SGP4 propagation and shown here in real-time. You can also run your own conjunction search directly in the browser using WebGPU. See also: satellite re-entries and Starlink satellite tracker.
